☕ Programación Orientada a Objetos (POO)

¡Bienvenido a mi repositorio de la materia de Programación Orientada a Objetos! 🚀

Aquí encontrarás todos los ejercicios, prácticas y proyectos desarrollados durante mi tercer semestre, enfocados en aprender y aplicar los pilares de la POO utilizando Java.

📂 Estructura del Repositorio

El espacio de trabajo está dividido en las siguientes carpetas principales:

📁 Ejercicio_1/: Prácticas iniciales sobre creación de clases, instanciación de objetos, constructores y métodos getter/setter (ej. Futbolista.java, Persona.java).

🎮 Visual Studio/CONSOLA DE VIDEOJUEGOS JAVA/: Proyecto práctico enfocado en la simulación de una consola de videojuegos mediante objetos.

🧪 pruebas_terminal/: Ejercicios rápidos de prueba y familiarización con la sintaxis de Java y la lectura de datos.

📚 GUIA JAVA.pdf: Material de apoyo, diagramas UML y apuntes de la materia.

🧠 Conceptos Abordados

A través de los códigos de este repositorio, se ponen en práctica conceptos clave como:

✔️ Clases y Objetos: Moldes e instancias.

✔️ Encapsulamiento: Modificadores de acceso, encapsulación de datos.

✔️ Interacción: Lectura de datos por consola (Scanner), uso de Arreglos (Arrays) y ciclos.

✔️ Próximamente: Herencia, Polimorfismo y Abstracción.

🛠️ Herramientas Utilizadas

Lenguaje Base: Java

Entorno de Desarrollo (IDE): Visual Studio Code

Gestor de Dependencias: Maven (pom.xml)

Control de Versiones: Git y GitHub
