Programación Orientada a Objetos (POO)

Este repositorio contiene las prácticas y ejercicios desarrollados durante el tercer semestre de la carrera de Ingeniería en Computación en el Centro Universitario de los Altos (CUAltos).

Estructura del Proyecto

-Ejercicio_1: Implementación de clases en Java mediante la simulación de un equipo de fútbol (clases Persona y Futbolista).

-Visual Studio/CONSOLA DE VIDEOJUEGOS JAVA: Prácticas enfocadas en el diseño de clases y constructores.

-pruebas_terminal: Códigos introductorios y pruebas de ejecución básica.

~GUIA JAVA.pdf: Documentación y apuntes de apoyo para la materia.

Tecnologías Utilizadas

Lenguaje: Java

Entorno de Desarrollo: Visual Studio Code / NetBeans
